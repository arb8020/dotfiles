HTML quality template

Accessible Report

Start here for generated reports that need strong visual character without fragile contrast, overflowing tables, or unreadable code blocks.

The foundation is intentionally opinionated: normalize layout at the edges, use tested color pairs, and ship a small inline validator that makes regressions visible in the console.

Elements

Boundary

External data should be normalized before it enters the trusted report body.

Invariant

Every visible text/background pair is designed to pass WCAG AA.

Fallback

Overflow is handled structurally, not by hoping content is short.

Code Blocks

Code blocks are dark text on a light background because that is the most reliable baseline for generated HTML with syntax spans.
